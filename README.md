# 🎣 Прогноз клёва

Статический сайт с прогнозом клёва рыбы на выбранную дату: от 30 дней назад (фактическая погода) до 15 дней вперёд. Сервер не нужен: погода берётся из бесплатного API
[Open-Meteo](https://open-meteo.com/), карта — OpenStreetMap через Leaflet, отчёты рыбаков хранятся в Supabase.

## Возможности

- Поиск по городу или водоёму (OpenStreetMap Nominatim, запасной — Open-Meteo), геолокация, выбор любой точки кликом по карте
- Выбор даты: календарь и кнопки ◀ ▶. Прошедшие дни — по фактической погоде, дальше 7 дней — с предупреждением о низкой точности
- 8 видов рыб: щука, окунь, судак, лещ, плотва, карп, карась, налим
- Индекс клёва 0–100 по дням, график по часам, лучшее окно, разбор факторов и советы
- **Зимний режим (со льда)**: включается автоматически, если неделю держится мороз, или вручную.
  Зимой иначе считаются активность видов, время суток (днём для окуня и плотвы, ночью для налима),
  выше вес давления, учитываются оттепель и сильный мороз
- **Отчёты об улове**: оценка клёва 1–5, снасть, приманка, глубина, количество, вес, имя и комментарий. Отчёты видны на карте и в списке,
  сайт показывает, насколько прогноз совпадает с реальными отчётами рядом

## Как считается индекс

Для каждого часа считаются 7 факторов (0…1) и объединяются взвешенным геометрическим средним.
Все коэффициенты лежат в `js/forecast.js`: профили рыб — `FISH`, веса — `W` (отдельно для открытой воды и льда).

| Фактор | Открытая вода | Со льда |
|---|---|---|
| Давление (уровень и скачки за 3 ч / 24 ч) | 25% | 32% |
| Температура воды / мороз и оттепель | 22% | 25% |
| Время суток (зорьки, день, ночь) | 18% | 20% |
| Ветер | 15% | 8% |
| Луна | 8% | 8% |
| Осадки | 7% | 5% |
| Облачность | 5% | 2% |

## Структура

```
index.html          разметка
css/style.css       стили (светлая и тёмная тема)
js/forecast.js      модель прогноза (чистые функции)
js/catches.js       отчёты об улове: Supabase REST или localStorage
js/app.js           интерфейс, карта, загрузка данных
js/config.js        адрес и публичный ключ Supabase
supabase/fishing_catches.sql  схема таблицы с RLS и защитой от спама
```

## Запуск локально

Откройте `index.html` в браузере или запустите любой статический сервер:

```bash
python3 -m http.server 8000
```

## Публикация

**Netlify Drop:** откройте https://app.netlify.com/drop и перетащите папку проекта.
Или подключите этот репозиторий в Netlify (Add new site → Import from Git) — сборка не нужна, publish directory: `/`.

**GitHub Pages:** Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.

## База отчётов

Ключ в `js/config.js` — публикуемый (publishable), его можно держать в открытом коде: посетители через него
могут только читать отчёты и добавлять новые (см. политики RLS в `supabase/fishing_catches.sql`).
Чтобы работать без базы, очистите поля в `js/config.js` — отчёты будут храниться в браузере.

## Подбор коэффициентов по отчётам

К каждому отчёту сохраняется индекс прогноза на тот час и значения всех факторов (`forecast_score`, `factors`).
Когда отчётов наберётся несколько сотен, веса можно подобрать регрессией. Начать можно с проверки в SQL Editor:

```sql
select fish, season, count(*), round(corr(forecast_score, rating)::numeric, 2) as corr
from fishing_catches where forecast_score is not null
group by fish, season order by count(*) desc;

-- какой фактор сильнее всего связан с реальным клёвом
select k, round(corr((factors->>k)::float, rating)::numeric, 2) as corr
from fishing_catches, unnest(array['pressure','temp','wind','time','precip','clouds','moon']) k
where factors is not null group by k order by corr desc;
```
